# Buzdolabı Işık Paradoksu Gözetmeni

> **Akademik Özet:** Kapı kapandığında içerideki ışığın sönüp sönmediği meselesi, çağdaş Türk mutfak metafiziğinin en yakıcı sorunudur. Bu depo o sorunu çözmez; sadece tutanak tutar.

## Neden var?

Çünkü herkes buzdolabını açınca ışığı görüyor, kapatınca da iddia ediyor. Biz iddiayı belgelendiriyoruz. Belge güçtür. Güç de bazen rafın arkasına saklanır.

## Kurulum (ciddi kısım)

```bash
python3 gozetmen.py
```

Python 3 yeter. Bağımlılık yok. Buzdolabı da yok. Hayal gücü zorunlu.

## Kullanım (daha az ciddi kısım)

Programa kapının kapalı olup olmadığını söyleyin. Program düşünecekmiş gibi yapacak, sonra rastgele ama özgüvenli bir karar verecek.

## Bilimsel yöntem

1. Kapıyı sor.
2. 0.4 saniye bekle (bu süre hakemlik ücretine dahildir).
3. Evrenin bir dalını seç.
4. Tutanağı bas.

## Sık sorulan sorular

**Işık gerçekten sönüyor mu?**  
Bilmiyoruz. Bilen varsa issue açsın.

**Bu yazılım enerjiden tasarruf eder mi?**  
Hayır. Hatta terminali açtığın için biraz harcadın.

**Copilot bunu onaylar mı?**  
Göreceğiz. Ona da soruşturma açtık.

## Gizlilik notu

Kaynak kodda `GIZLI` adlı bir satır vardır. Base64'tür. Rafta durur. Siyasi parti reklamı değildir; genel bir hukuk–denetim cümlesidir. Kimse bakmasın diye oraya konmuştur. Baktıysan artık sen de gözetmensin.
